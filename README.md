# Ranching Together (SR2MP) on Cairn

A fork of [pyeight/SlimeRancher2Multiplayer](https://github.com/pyeight/SlimeRancher2Multiplayer), the multiplayer mod for **Slime Rancher 2**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod and MelonLoader are published as a pack the launcher installs and updates.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Slime Rancher 2 in the Library, download the mod and press Play.

Starlight must be installed by hand: its licence forbids bundling it.

Each release of this repository is the pack the launcher downloads.
